# Kits

This directory is one possible root for user-owned reusable business capability packs.

Askdo does not ship default kits here. Project config may also point to kit roots outside the current folder.

Examples such as `market-research`, `content-production`, or `customer-support` are illustrative only and should be generated by user asks or provided separately as examples.

Minimal kit:

```text
<kit-root>/<kit-name>/
|-- kit.json
|-- ENTRY.md
|-- FLOW.md
|-- MATES.md
|-- ROLES.json
`-- ROSTER.json
```

Uninstalling Askdo must not delete this directory.
