# Kits

This directory is for user-owned reusable business capability packs.

Askdo does not ship default kits here.

Examples such as `market-research`, `content-production`, or `customer-support` are illustrative only and should be generated by user asks or provided separately as examples.

Minimal kit:

```text
kits/<kit-name>/
|-- kit.json
|-- FLOW.md
`-- MATES.md
```

Uninstalling Askdo must not delete this directory.
