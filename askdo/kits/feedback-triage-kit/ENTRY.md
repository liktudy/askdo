# Feedback Triage Kit Entry

## Use This Kit

```text
use askdo kit feedback-triage-kit: classify feedback into priorities and actions
```

## Purpose

Turn a medium-size feedback set into a triage report and action table.

## Run Gate

This kit can run only when:

- `kit.json` status is `active`.
- `build_approval.status` is `approved`.
- the ask is about local user-provided feedback.
- no private customer data is exposed outside the workspace.
- no external network or production system write is required.

## Input

- Customer feedback items supplied by the user or generated by the host agent for a safe test run.

## Output

- `FEEDBACK_TRIAGE.md`
- `ACTION_TABLE.csv`

## Decision Request

If approval is missing, create a choice gate and wait.
