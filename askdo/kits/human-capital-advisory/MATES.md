# Human Capital Advisory Mates

## Crew

Source: `ROLES.json`

Name: Enterprise Human Capital Advisory Crew

Purpose: Act as an external advisory brain for enterprises that need deeper organizational diagnosis, tailored operating design, and disciplined implementation support.

## Role Contract

Source: `ROLES.json`

Roles are stable responsibility seats. Shared roles use archetypes and scenario bindings so the same role pattern can adapt across diagnosis, design, implementation, and review scenarios.

## Mate Roster

Source: `ROSTER.json`

Mates are concrete workers assigned to roles. Add, remove, pause, or replace mates in `ROSTER.json`; update this Markdown only when the operating contract changes.

## Assignment Notes

- Assignments are created per run.
- Each assignment must be owned by one active mate from `ROSTER.json`.
- A mate may receive multiple assignments only when they fit its responsibility.
- High-risk HR execution, employee-impacting decisions, or compliance claims require escalation before execution.

## Change Rules

- Role changes go in `ROLES.json`.
- Employee or mate changes go in `ROSTER.json`.
- Flow routing changes go in `FLOW.md`.
- Execution entry changes go in `ENTRY.md`.
- This file summarizes the operating contract and should not become the roster database.
