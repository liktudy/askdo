# Plane Shooter Game Entry

## Use This Kit

```text
use askdo kit plane-shooter-game: <browser arcade game ask>
```

## Purpose

Create, test, and package a small browser-based plane shooter game as a downloadable deliverable.

## Run Gate

This kit can run only when:

- `kit.json` status is `active`.
- `build_approval.status` is `approved`.
- the ask fits small browser arcade game creation, testing, and packaging.
- requested file writes stay inside the current run result directory.

## Inputs

- Game theme or constraints.
- Desired delivery format.
- Testing or packaging requirements.

## Outputs

- Standalone browser game files.
- Test files when useful.
- Zip package when requested.

## When To Refuse Or Revise

- Refuse execution when the ask exceeds small browser game delivery.
- Request approval when the ask needs destructive actions, external publishing, or broad project changes.
- Revise the kit when the requested game needs roles or mates not covered by `ROLES.json` and `ROSTER.json`.
