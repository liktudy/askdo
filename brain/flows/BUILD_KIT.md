# Build Kit Flow

## Purpose

Build a reusable kit from a user ask when no existing kit can naturally handle the need.

## Required Outputs

```text
kits/<kit-name>/kit.json
kits/<kit-name>/FLOW.md
kits/<kit-name>/MATES.md
```

## Flow

1. Understand the ask.
2. Check existing kits for reuse.
3. Define kit purpose and boundary.
4. Define the flow.
5. Define mates and their permissions.
6. Write `kit.json`, `FLOW.md`, and `MATES.md`.
7. Check the new kit against rules and schemas.
8. Stop for approval when risk, permission, or boundary rules require it.

## Do Not

- Do not build a kit when reuse is sufficient.
- Do not generate extra crews or mates for possible future use.
- Do not combine unrelated responsibilities into one mate.
