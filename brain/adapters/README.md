# Adapters

Adapters connect Askdo to host agent tools such as Codex, Claude Code, Cursor, and OpenCode.

Adapters may change runtime shape, but they must not redefine source of truth.

Source of truth remains:

- `brain/rules/`
- `brain/schemas/`
- `brain/flows/`
- `kits/*/kit.json`
- `kits/*/FLOW.md`
- `kits/*/MATES.md`
